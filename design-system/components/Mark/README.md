# Mark

The Kadmium mark drawn inline — the head plate and four rods — so it takes `currentColor` for the rail and the theme's cadmium for the rods. Use it in headers, the sidebar and empty states; for files to embed elsewhere, use the SVGs in `assets/Logos`.

You provide `size` in px (minimum 20) and `tone="mono"` where cadmium is unavailable or the mark sits on a cadmium ground. Keep one rod pitch of clear space around it (10/64 of its height) and never rotate, recolour or outline it. Set the name beside it in Archivo 650 at the cap-height relation the wordmark file fixes, or use the wordmark SVG.
