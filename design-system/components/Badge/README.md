# Badge

One or two words of placement or status in mono uppercase. `local` and `cloud` say where compute runs; `ok`, `warn` and `danger` say how it is doing; `neutral` names things (a model id, a protocol).

You provide the word (use the fabric's vocabulary: resident, training, prefetching, joining, yielded, throttled, offline, faulted) and `dot` for live states. Never a sentence, never a count — use a `Tabs` count or plain mono text for numbers. Colour never carries the meaning alone: the word is always present.
