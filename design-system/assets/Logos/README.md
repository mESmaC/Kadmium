# Logos

The Kadmium mark, wordmark, tiles and favicon. All SVG; every file names its own colours, so they display correctly through `<img>` — pick the file for the ground you are placing it on.

- `kadmium-mark-dark.svg` — the two-colour mark for dark grounds: rods `#f3c020` (cadmium), rail `#eceff3` (ink).
- `kadmium-mark-light.svg` — the same for light grounds: rods `#f3c020`, rail `#15181c`.
- `kadmium-mark-mono-dark.svg` — single ink `#eceff3`, for dark grounds where cadmium is unavailable.
- `kadmium-mark-mono-light.svg` — single ink `#15181c`, for light grounds.
- `kadmium-wordmark-dark.svg` — mark + *Kadmium* in Archivo 650 as outlines, ink `#eceff3`; 495 × 64 units.
- `kadmium-wordmark-light.svg` — the same, ink `#15181c`.
- `kadmium-tile-graphite.svg` — 128px app tile, `#16191e` ground, 22 % corner radius, two-colour mark at 60 %.
- `kadmium-tile-cadmium.svg` — 128px app tile, `#f3c020` ground, single-ink mark in `#141414` (on-cadmium).
- `kadmium-favicon.svg` — 32px graphite tile with a three-rod cut drawn for 16–32px.

Clear space is one rod pitch (10/64 of the mark's height) on every side; minimum sizes are 20px (mark), 16px (favicon), 96px wide (wordmark). The rules — no rotation, no other colours, no extra rods, no ring — are in the brand book's *Marks, pattern and iconography* section.
